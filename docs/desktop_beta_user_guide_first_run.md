# FedOS Desktop Beta — First-Run Guide

On first launch, you see a **Welcome** screen — this device has no local
profile yet.

1. Click **Create a profile**.
2. Enter a label for yourself (only shown to you, locally) and a
   passphrase. This passphrase seals your account's Master Seed on this
   device — **it is never stored anywhere, and cannot be recovered if you
   forget it.** Choose one you will remember, or store it in a password
   manager.
3. Confirm the passphrase and submit.

You land on the **Conversations** screen, unlocked and ready. A navigation
bar at the top lets you reach Search, Archive, Devices, Safety Center, and
Settings.

Before you can invite a contact or exchange messages, you need at least
one Relay configured — see the Relay Setup Guide
(`docs/desktop_beta_user_guide_relay_setup.md`).

On every later launch, you unlock the SAME profile with the same
passphrase instead of creating a new one.
