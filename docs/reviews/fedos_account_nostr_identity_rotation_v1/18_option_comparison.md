## Chosen: **G — entirely new identity with an explicit, optional, evidence-leveled continuity claim**

Every other option either (a) fails exactly under the threat this
document set exists to defend against (B, C, D — `09`), (b) requires
inventing a primitive this codebase has no foundation for (F, and E's
"true rotation" framing), (c) provides zero recovery path at all (A), or
(d) doubles the implementation and reasoning burden for no compensating
safety benefit (H). **G is the only option that is simultaneously honest
under compromise, fully recoverable from total loss, low implementation
risk (reuses four already-live mechanisms), and requires zero changes to
Nostr-level semantics.** This is the same conclusion `3ebfa37` reached
independently (its own "Option 1 + Option 7" combination is exactly this
review's G, described before the evidence-level vocabulary and
peer-capability integration existed to make it concrete) — this review
reaffirms it with the added precision `07`-`17` provide.
