## Component 4 — TypeScript-side cryptographic dependency (cross-cutting)

`@noble/curves`/`@noble/hashes` (Component 1's own direct dependencies)
are used for real, production cryptographic operations OUTSIDE the Rust/
WASM boundary — specifically Signed Deletion Request signing (BIP-340
Schnorr) — see [`10_dependency_manifest.md`](10_dependency_manifest.md)
for the exact call site. Listed again here because an SBOM organized
purely by "which package.json/Cargo.toml declares it" would bury this
cross-boundary crypto dependency inside a 94-entry npm list where an
auditor scanning for "cryptographic components" might miss it.

per-package license identifiers and known-vulnerability cross-references
in one pass, which this manually-assembled document splits across
[`15_license_inventory.md`](15_license_inventory.md) and the
not-yet-run `cargo audit`/`npm audit` (see
