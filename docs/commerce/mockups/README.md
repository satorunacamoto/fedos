# Commerce Mockups — CONCEPTUAL, NOT CURRENT PRODUCT UI

Every file in this directory is a documentation-only mockup created for the End-to-End Commerce audit ([../FEDOS-COMMERCE-END-TO-END.md](../FEDOS-COMMERCE-END-TO-END.md)). **None of it exists in the shipping FedOS Desktop application.** The real shipping app has exactly six screens — Conversations, Search, Archive, Devices, Safety Center, Settings — and no commerce surface of any kind (see [../PRODUCT-SURFACE-AUDIT.md](../PRODUCT-SURFACE-AUDIT.md)).

These mockups exist to make the *minimum useful product surface* concrete for future design discussion. They are not wireframes of planned work, not a commitment, and not a description of anything a user can click today.
